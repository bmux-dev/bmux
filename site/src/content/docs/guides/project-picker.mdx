**Ctrl-a n**, or `bmux project` from a shell, opens a centered popup (80% of the
screen) over the current view, with two tabs. **Tab** switches between them.
The picker's and the sidebar's **n** open the same popup.

## Projects tab

Lists project folders, like sesh and tmux-sessionizer:

1. folders a session started in, most recently used first, with the session's
   name;
2. git repositories under `projects.roots` (`~/code`, `~/src`, `~/projects`
   and `~/dev` by default, when they exist), up to `projects.depth` levels
   down (3). Hidden folders, `node_modules`, `vendor` and folders inside a
   repository aren't searched.

<Screenshot name="project-picker" alt="The new-session popup listing session folders and git repositories" />

Typing filters the list; Up/Down (or Ctrl-j/k, Ctrl-n/p) select, Backspace
and Ctrl-u edit the filter. **Enter** attaches to the most recent session
started in that folder, or creates one named after it, the way bare `bmux`
names sessions. When nothing matches the filter, **Enter** opens the Create tab
with the filter as the session name. **Esc** closes the popup; when
`bmux project` opened it, bmux exits. `bmux project DIR` does the same for one
folder without the popup. Folders reached through a symlink are the same
folder.

## Create tab

**Tab** (or Enter with no match) opens a form with a start directory, a
session name and a *Create directory if it doesn't exist* toggle, with the
directory focused. The directory starts as `projects.start-dir` if you set it,
else the highlighted project's folder, else the folder you started bmux in.
The name starts empty, because it is usually the folder's name: leave it empty
and the session is named after the directory the way bare `bmux` names
sessions, numbered if taken (`api-2`). Type a name to override it. A filter you
typed that didn't pick a project becomes the name.
Up/Down move between the fields, Backspace and Ctrl-u edit the focused text
field, and **Enter** creates the session and attaches to it. A relative
directory is relative to the start directory, and `~` is your home directory.

The toggle is on by default: a start directory that doesn't exist is created,
parents included, before the session starts. Turn it off with **Space** (or
Left/Right) while it's focused and a missing directory is an error instead.
The start directory is where you started bmux unless `projects.start-dir` names
another folder.

In the directory field, **Tab** completes the path like a shell: one matching
folder completes to it plus a slash, several complete to what they share, and
a Tab that can't add anything lists the matches. Only folders are offered, and
hidden ones only after you type a dot. **Esc** (or **Tab** in the name field)
returns to the Projects tab without creating anything.
